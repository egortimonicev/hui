# Бригада

Мини-приложение Telegram для строительных бригад: табель, ежедневные отчёты, важные объявления, задачи и заявки
на материалы. Сейчас работает в браузере в демо-режиме; на сервер и в Telegram переносится без переделок.

## Идея

На стройке всё держится на бригадире, а у него — блокнот, звонки и чат, где важное тонет через час.
«Бригада» собирает ежедневную рутину в одном окне и подстраивается под роль: каждый видит только то,
что ему нужно, и главное действие дня всегда на первом экране.

| Роль | Главное на экране | Что может |
| --- | --- | --- |
| **Бригадир** | Кто на объекте, отчёт за день | Отмечает людей, пишет отчёты, публикует объявления, ставит задачи, оформляет заявки, добавляет рабочих |
| **Начальник** | Сводка по всем бригадам, что ждёт решения | Принимает или возвращает отчёты, одобряет заявки, правит табель за любой день, управляет командой |
| **Рабочий** | Отмечен ли сегодня, часы за месяц | Видит свой табель, задачи и объявления, подтверждает «Ознакомлен» |

## Что внутри

- **Табель.** Отметка в одно касание (на месте / опоздал / не вышел), кнопка «Остальные на месте», часы,
  больничный, отгул и комментарий — в карточке человека. Отметки сохраняются мгновенно. Вид «Месяц» — сетка
  по всей бригаде со сменами и часами. Бригадир правит сегодня и три дня назад, дальше — только начальник.
- **Отчёты.** Работы с объёмами, проблемы и простои, план на завтра, до 8 фото (сжимаются на телефоне).
  Люди и часы подтягиваются из табеля. Начальник принимает отчёт или возвращает с замечанием.
- **Объявления.** Обычные, важные и срочные; закрепление сверху. Для важного включается «Ознакомлен» —
  автор видит, кто прочитал, а кто нет.
- **Задачи.** Конкретному человеку или всей бригаде, со сроком и приоритетом; просроченные подсвечиваются.
- **Заявки.** Материалы и инструмент: бригадир оформляет, начальник одобряет или отклоняет с причиной,
  получение отмечается на объекте.
- **Команда.** Бригады, объекты, телефоны (звонок в одно касание), личные ссылки-приглашения.

Интерфейс рассчитан на стройку: крупные кнопки, высокий контраст, светлая и тёмная темы.

## Запуск

Нужен Node.js 22.18 или новее.

```bash
npm install
npm run dev        # http://localhost:3000
```

База создаётся сама (`data/brigada.db`, SQLite) и заполняется демо-данными: две бригады, три недели табеля,
отчёты, объявления, задачи и заявки. На экране входа выберите, под кем зайти.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Сервер и интерфейс на одном порту, с автообновлением |
| `npm run build` | Сборка интерфейса в `dist/` |
| `npm start` | Боевой режим: API и собранный интерфейс |
| `npm run seed` | Стереть базу и заново залить демо-данные |
| `npm test` | Тесты API: права ролей, табель, отчёты, вход через Telegram |
| `npm run typecheck` | Проверка типов |

## Перенос на сервер и в Telegram

1. Создайте бота в [@BotFather](https://t.me/BotFather) и получите токен.
2. На сервере: `cp .env.example .env`, заполните `BOT_TOKEN`, `BOT_USERNAME` и `ADMIN_TG_ID` — ваш числовой
   Telegram ID, с ним при первом запуске создаётся начальник.
3. `npm ci && npm run build && npm start` — приложение слушает `PORT` (по умолчанию 3000).
4. Telegram открывает мини-приложения только по HTTPS: поставьте перед приложением nginx или Caddy с сертификатом.
5. В BotFather укажите адрес как Main Mini App (`/mybots` → Bot Settings → Configure Mini App).
6. Добавляйте людей в разделе «Команда» и отправляйте им личные ссылки-приглашения.

Как только задан `BOT_TOKEN`, демо-вход отключается: пользователь определяется по подписанным данным Telegram,
а человек без приглашения в приложение не попадёт. Без токена в боевом режиме сервер не запустится, пока демо
не разрешено явно (`DEMO_MODE=1`).

Все данные лежат в папке `data/` (база и фото отчётов) — её достаточно для резервной копии.

## Устройство

```
server/        API на Express, SQLite через встроенный node:sqlite
  routes/      табель, отчёты, объявления, задачи, заявки, команда
  auth.ts      проверка подписи Telegram и демо-вход
  seed.ts      демо-данные
shared/        типы, общие для сервера и интерфейса
src/           интерфейс на React, Tailwind CSS
  pages/       экраны
  ui.tsx       общие компоненты
tests/         тесты API
```

## Что ещё не сделано

- Фото отчётов доступны по прямой ссылке со случайным именем файла, без проверки входа.
- Нет выгрузки табеля в Excel.
